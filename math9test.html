Question 1: Set Theory 5 Marks

If $n(U) = 45$, $n(X \cap Y) = 15$, $n(X) = 20$ and $n(Y) = 25$, then find:

i. $n(X \cup Y)$

ii. $n_0(Y)$

iii. $n(\overline{X \cup Y})$

iv. Show all the information in a Venn diagram.

Step-by-Step Solution:

Given Data: $n(U) = 45$, $n(X \cap Y) = 15$, $n(X) = 20$, $n(Y) = 25$


i. To find $n(X \cup Y)$:

$$n(X \cup Y) = n(X) + n(Y) - n(X \cap Y)$$ $$n(X \cup Y) = 20 + 25 - 15 = 30$$

ii. To find $n_0(Y)$ (elements in Set Y only):

$$n_0(Y) = n(Y) - n(X \cap Y) = 25 - 15 = 10$$

iii. To find $n(\overline{X \cup Y})$ (elements outside sets X and Y):

$$n(\overline{X \cup Y}) = n(U) - n(X \cup Y) = 45 - 30 = 15$$

iv. Venn Diagram Representation:

Calculations for set regions: $n_0(X) = 20 - 15 = 5$, $n(X \cap Y) = 15$, $n_0(Y) = 10$, $\text{Outside} = 15$.

Question 2: Mensuration - Hall Dimensions & Costing 5 Marks

A rectangular hall is $6\text{ m}$ long, $5\text{ m}$ broad and $4\text{ m}$ high. It contains $2$ doors of size $2\text{ m} \times 3\text{ m}$ and $3$ windows of size $2\text{ m} \times 1.75\text{ m}$.

i. Find the area of the floor.

ii. Find the area of 4 walls excluding doors and windows.

iii. What is the cost of papering 4 walls at $\text{Rs. } 200\text{ per m}^2$?

iv. Find the cost of curtains for the doors and windows at $\text{Rs. } 500\text{ per m}^2$.

Step-by-Step Solution:

Given: Length ($l$) = $6\text{ m}$, Breadth ($b$) = $5\text{ m}$, Height ($h$) = $4\text{ m}$


i. Area of the floor:

$$\text{Area} = l \times b = 6 \times 5 = \mathbf{30\text{ m}^2}$$

ii. Area of 4 walls excluding doors and windows:

$$\text{Area of 4 walls (including openings)} = 2h(l + b) = 2 \times 4 \times (6 + 5) = 8 \times 11 = 88\text{ m}^2$$ $$\text{Area of 2 doors} = 2 \times (2 \times 3) = 12\text{ m}^2$$ $$\text{Area of 3 windows} = 3 \times (2 \times 1.75) = 10.5\text{ m}^2$$ $$\text{Total openings area} = 12 + 10.5 = 22.5\text{ m}^2$$ $$\text{Area of 4 walls excluding openings} = 88 - 22.5 = \mathbf{65.5\text{ m}^2}$$

iii. Cost of papering the 4 walls:

$$\text{Cost} = 65.5\text{ m}^2 \times \text{Rs. } 200/\text{m}^2 = \mathbf{\text{Rs. } 13,100}$$

iv. Cost of curtains for doors and windows:

$$\text{Cost} = 22.5\text{ m}^2 \times \text{Rs. } 500/\text{m}^2 = \mathbf{\text{Rs. } 11,250}$$
Question 3: Mensuration - Triangular Prism 5 Marks

The volume of a prism having its base as a right-angled triangle is $840\text{ cm}^3$. The lengths of the sides of the right-angled triangle containing the right angle are $8\text{ cm}$ and $6\text{ cm}$.

i. Find the area of the base.

ii. Find the height of the prism.

iii. Find the total surface area of the prism.

Step-by-Step Solution:

Given: Volume ($V$) = $840\text{ cm}^3$, Base legs $a = 8\text{ cm}$, $b = 6\text{ cm}$.


i. Area of the base ($B$):

$$B = \frac{1}{2} \times \text{base} \times \text{height} = \frac{1}{2} \times 8 \times 6 = \mathbf{24\text{ cm}^2}$$

ii. Height of the prism ($h$):

$$\text{Volume} = B \times h \implies 840 = 24 \times h \implies h = \frac{840}{24} = \mathbf{35\text{ cm}}$$

iii. Total Surface Area ($\text{TSA}$) of the prism:

First find the hypotenuse ($c$) of the base triangle:

$$c = \sqrt{a^2 + b^2} = \sqrt{8^2 + 6^2} = \sqrt{64 + 36} = \sqrt{100} = 10\text{ cm}$$ $$\text{Perimeter of base } (P) = a + b + c = 8 + 6 + 10 = 24\text{ cm}$$ $$\text{Lateral Surface Area } (\text{LSA}) = P \times h = 24 \times 35 = 840\text{ cm}^2$$ $$\text{Total Surface Area } (\text{TSA}) = \text{LSA} + 2 \times B = 840 + 2(24) = 840 + 48 = \mathbf{888\text{ cm}^2}$$
Question 4: Mensuration - Cylinder Volume 5 Marks

A $30\text{ cm}$ high cylinder with a $14\text{ cm}$ diameter is cut vertically into two equal halves. What is the volume of a half part?

Step-by-Step Solution:

Given Data:

Height of cylinder ($h$) = $30\text{ cm}$

Diameter ($d$) = $14\text{ cm} \implies \text{Radius } (r) = \frac{14}{2} = 7\text{ cm}$


Step 1: Calculate full cylinder volume ($V$):

$$V = \pi r^2 h = \frac{22}{7} \times 7^2 \times 30 = 22 \times 7 \times 30 = 4620\text{ cm}^3$$

Step 2: Calculate volume of half part:

$$\text{Volume of half part} = \frac{V}{2} = \frac{4620}{2} = \mathbf{2310\text{ cm}^3}$$
Question 5: Trigonometry - Heights & Distances 5 Marks

The height of an electric pole is $5\sqrt{3}\text{ m}$. Its top is observed from a point $15\text{ m}$ away from its foot. Find the reference angle of elevation.

Step-by-Step Solution:

Let $\theta$ be the reference angle of elevation.

Opposite side ($\text{Height of pole}, h$) = $5\sqrt{3}\text{ m}$

Adjacent side ($\text{Distance from foot}, d$) = $15\text{ m}$


Using the tangent ratio:

$$\tan\theta = \frac{\text{Opposite}}{\text{Adjacent}} = \frac{5\sqrt{3}}{15}$$ $$\tan\theta = \frac{\sqrt{3}}{3} = \frac{1}{\sqrt{3}}$$ $$\text{Since } \tan 30^\circ = \frac{1}{\sqrt{3}}, \text{ we have:}$$ $$\theta = \mathbf{30^\circ}$$

Answer: The reference angle of elevation is $30^\circ$.

Question 6: Algebra - Factorization 5 Marks

Factorize the following algebraic expression completely:

$$x^2 - 10x + 24 + 6y - 9y^2$$

Step-by-Step Solution:

Given expression: $x^2 - 10x + 24 + 6y - 9y^2$


Step 1: Rearrange and complete the square by writing $24$ as $25 - 1$:

$$= x^2 - 10x + 25 - 1 + 6y - 9y^2$$

Step 2: Group into perfect square terms:

$$= (x^2 - 10x + 25) - (9y^2 - 6y + 1)$$ $$= (x - 5)^2 - (3y - 1)^2$$

Step 3: Apply difference of two squares identity $a^2 - b^2 = (a - b)(a + b)$:

$$= [(x - 5) - (3y - 1)][(x - 5) + (3y - 1)]$$ $$= (x - 5 - 3y + 1)(x - 5 + 3y - 1)$$ $$= \mathbf{(x - 3y - 4)(x + 3y - 6)}$$
Question 7: Algebra - Highest Common Factor (H.C.F.) 5 Marks

Find the H.C.F. of the following algebraic expressions:

$$x^2 - 4y^2, \quad x^2 + xy - 2y^2, \quad \text{and} \quad (x - 2y)^2 + 8xy$$

Step-by-Step Solution:

1st Expression:

$$x^2 - 4y^2 = (x - 2y)(x + 2y)$$

2nd Expression:

$$x^2 + xy - 2y^2 = x^2 + 2xy - xy - 2y^2$$ $$= x(x + 2y) - y(x + 2y) = (x + 2y)(x - y)$$

3rd Expression:

$$(x - 2y)^2 + 8xy = x^2 - 4xy + 4y^2 + 8xy$$ $$= x^2 + 4xy + 4y^2 = (x + 2y)^2 = (x + 2y)(x + 2y)$$

Finding H.C.F. (Common factors in all three expressions):

$$\text{Common factor} = (x + 2y)$$ $$\mathbf{\text{H.C.F.} = x + 2y}$$
Question 8: Algebra - Lowest Common Multiple (L.C.M.) 5 Marks

Find the L.C.M. of the following expressions:

$$24x^2 - 54, \quad 16x^2 - 48x + 36, \quad \text{and} \quad 12x^2 - 6x - 18$$

Step-by-Step Solution:

1st Expression:

$$24x^2 - 54 = 6(4x^2 - 9) = 6(2x - 3)(2x + 3)$$

2nd Expression:

$$16x^2 - 48x + 36 = 4(4x^2 - 12x + 9) = 4(2x - 3)^2$$

3rd Expression:

$$12x^2 - 6x - 18 = 6(2x^2 - x - 3) = 6(2x^2 - 3x + 2x - 3)$$ $$= 6[x(2x - 3) + 1(2x - 3)] = 6(2x - 3)(x + 1)$$

Finding L.C.M.:

- Numerical coefficients: $\text{L.C.M.}(6, 4, 6) = 12$

- Polynomial factors: Highest powers of $(2x - 3)^2$, $(2x + 3)$, and $(x + 1)$

$$\mathbf{\text{L.C.M.} = 12(x + 1)(2x + 3)(2x - 3)^2}$$
Question 9: Indices & Exponents - Simplification 5 Marks

Simplify the following exponential expression:

$$\left(\frac{x^b}{x^{-a}}\right)^{b-a} \times \left(\frac{x^a}{x^{-c}}\right)^{a-c} \times \left(\frac{x^c}{x^{-b}}\right)^{c-b}$$

Step-by-Step Solution:

Step 1: Simplify each factor using index laws $\frac{1}{x^{-n}} = x^n$:

$$\text{1st Factor: } \left(\frac{x^b}{x^{-a}}\right)^{b-a} = \left(x^{b - (-a)}\right)^{b-a} = \left(x^{b+a}\right)^{b-a} = x^{(b+a)(b-a)} = x^{b^2 - a^2}$$ $$\text{2nd Factor: } \left(\frac{x^a}{x^{-c}}\right)^{a-c} = \left(x^{a - (-c)}\right)^{a-c} = \left(x^{a+c}\right)^{a-c} = x^{(a+c)(a-c)} = x^{a^2 - c^2}$$ $$\text{3rd Factor: } \left(\frac{x^c}{x^{-b}}\right)^{c-b} = \left(x^{c - (-b)}\right)^{c-b} = \left(x^{c+b}\right)^{c-b} = x^{(c+b)(c-b)} = x^{c^2 - b^2}$$

Step 2: Multiply factors by adding exponents ($x^m \times x^n = x^{m+n}$):

$$= x^{(b^2 - a^2) + (a^2 - c^2) + (c^2 - b^2)}$$ $$= x^0 = \mathbf{1}$$
