SRAM vs. DRAM

A simple interactive guide to how memory works.

Static RAM (SRAM)

The Core Logic: SRAM uses a "Flip-Flop" circuit (made of 6 transistors). It works like a light switch.

  • Once you set it to "1", it stays "1" as long as power is connected.
  • It is extremely fast because it doesn't need to do anything to maintain its state.
Analogy: A digital scoreboard. Once you set the score, it stays there until you change it. No maintenance required.

Dynamic RAM (DRAM)

The Core Logic: DRAM uses a Capacitor (like a tiny battery). It works like a leaky bucket.

  • It stores a "1" as an electric charge, but that charge leaks out very quickly.
  • It must be "refreshed" (refilled) thousands of times per second or it forgets the data.
Analogy: Spinning a top. To keep it spinning (data alive), you have to keep giving it a flick (refresh). If you stop, it falls over.

Why do we use both?

We use SRAM for the "Brain" (CPU Cache) because the CPU needs data instantly. We use DRAM for the "Library" (System RAM) because we need huge amounts of space at a low price.
