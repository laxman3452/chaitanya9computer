Display Technology Explorer

Liquid Crystal Display (LCD)

The foundation of modern flat screens.

How it works: Think of LCD as a window with shutters. The liquid crystals don't make light; they just block or allow light from a backlight to pass through.

Light Emitting Diode (LED)

A better, brighter version of LCD.

The Secret: An LED screen is an LCD screen. The only difference is that it uses tiny LED bulbs as the backlight instead of old fluorescent tubes.
  • Efficient: Uses less battery.
  • Slim: LEDs are tiny, so the TV can be thinner.

Organic LED (OLED)

The premium "Self-Emissive" technology.

How it works: No backlight needed! Each pixel is like a tiny independent light bulb. If the image is black, the pixel turns off completely.
